# TechSphere - Frontend

TechSphere is a professional training platform focused on front-end web development. It provides learners with live and recorded sessions, real-world projects, and hands-on portfolio building.

## 🚀 Features

- ✅ Responsive UI built with React
- ✅ Routing with React Router
- ✅ Form handling and validations
- ✅ API integration with a Node.js + MongoDB backend
- ✅ Modular component structure
- ✅ Clean and modern design
